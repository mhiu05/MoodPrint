# S-07 — Shape of the image call

Status: **RESOLVED** by live evidence (`gpt-6-luna`, openai 3.46.0, openai-agents 0.24.0).

## Decision

The reader calls `AsyncOpenAI.responses.parse(model, instructions, input=[{role:user, content:[
input_text, input_image(data URL, detail=auto)]}], text_format=EvidenceReading, store=False,
max_output_tokens=2500, reasoning={effort: medium})` directly. It is one request with a structured
output schema and no session, tools or handoff, and it passes through the same budget-guarded
transport as every other paid call. `Runner` is not used for images.

## Evidence

* L-AG-04 (`agent/evals/results/live-compat-2026-11-08.json`): a synthetic 256×256 PNG saying
  "Xin chào" was read back with exact diacritics; 1,075 tokens, ~6 s.
* 8 rendered Messenger-style fixtures (`agent/evals/fixtures/messenger_0N.png`), run `final2-b`:
  8/8 returned schema-valid readings; verbatim text, shown timestamps/participants and uncertainties
  were reported; the only inference per image was a low-risk "this looks like an illustration".
  Latency 4.1–7.3 s per image (p95 well under the 40 s target), 1.8–2.3 K tokens (~US$0.0003) each.
* Prompt-injection text inside images is covered by unit/integration tests (kept as extracted text,
  never as an instruction); no live image carrying an instruction was run.

## Limits

* Only PNG/JPEG/WebP are accepted; formats are decided by magic bytes, animated images are refused,
  EXIF/metadata is stripped by rebuilding from pixels, and size/pixel limits are enforced before
  anything is sent (`agent/tests/test_evidence_image.py`).
* Image reading quality on real screenshots (handwriting, low contrast, non-Vietnamese) is
  unmeasured; all fixtures are clean synthetic renders.
