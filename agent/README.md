# Agent — module độc lập trong tương lai

Chưa triển khai. Package Python `moodprint_agent` dự kiến gồm companion, orchestration, tools, knowledge, multimodal, memory, roleplay và guardrails; evals/tests riêng. OpenAI Agents SDK là hướng tham khảo, chưa cài đặt. Backend có thể gọi qua `agent_gateway`; việc tách module không bắt buộc tách process. UI hiện chỉ phát lại mock scripts trong frontend.
