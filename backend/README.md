# Backend — kiến trúc tương lai

Chưa triển khai. FastAPI dự kiến quản lý auth, hồ sơ, evidence, kế hoạch, support, knowledge, school integration và OpenAPI contracts. Cấu trúc tương lai: `app/api`, `app/core`, `app/modules`, `app/schemas`, `app/infrastructure`, `app/agent_gateway` (thin adapter). Database/Auth dự kiến Supabase/PostgreSQL. Không có server, migration, Python dependency hoặc kết nối production trong prototype. Xem ../docs/prototype/06-FUTURE-TECHNICAL-ARCHITECTURE.md.
