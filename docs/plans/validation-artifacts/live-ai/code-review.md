# Final change review

24 October2026. Primary-agent review of the working tree; no independent reviewer or human calibration is claimed. Scope: provider/observer, local actor scopes, prompt selection, bounded context, ledger/migration/recovery, retention, draft/Markdown rendering and evaluation/browser harnesses.

Verified paths:

- HTTP actors cannot select model overrides or prompt variants. Local allowlist is development-only; runtime acceptance and provider invocation validate it. Auth subjects are resolved to existing application actor IDs. Session voice availability and STT invocation share the local scope. Normal auth/age/consent remain mandatory.
- No model-facing tool performs durable writes. Proposal, receipt and domain authorization remain separate. MEM-disabled runs omit memory proposals; tool execution still rechecks permission/data version. Nhịp arguments cannot select an owner or unapproved date range; query selects scores/version only. Cầu Nối receives no private memories/transcripts.
- Usage starts persist before model execution; completed receipts survive output guardrail rejection. Cancellation without a receipt remains uncertain. Snapshots cannot regress or double-count; worker ownership/lease checks fence stale writes. Usage→run lock order is consistent between settlement and recovery. Recovery scans only open expired rows and never replays a provider call. Cleanup queries table existence so disabling capture does not retain old accounting forever or break pre-migration hosted schemas.
- New SQL is expand-only, enables RLS, grants only the existing trusted backend role and revokes public/client-role access to the new table. Existing Auth/RLS SQL is not rewritten. Exact reviewed SQL/hash and local rehearsal are saved; no hosted execution occurred.
- Context remains bounded and bot/actor/session-scoped. Latest input is retained and corrections stay chronological. No unvalidated compaction or cross-bot retrieval was introduced.
- Draft restoration applies to a confirmed failed terminal only and preserves an already-entered new draft. Network interruption requires reconciliation. Markdown parses into restricted React elements, skips raw HTML and exposes no active links/images. Tests exercise formatting and active-content denial. Parser is loaded separately from the initial app bundle.
- Paid evaluation loops are finite, do not retry, refuse artifact overwrite and have no fake fallback. Synthetic content is saved deliberately; private prompts, keys, credentials, headers and real audio are excluded. Live HTTP telemetry stores counts/tool names only.

Addressed during review: provider availability check at the wrong shared-tool boundary; Auth-subject/internal-ID fixture mismatch; recovery lock order and settled-row starvation; retention after capture kill switch; legacy migration lint/import registration; draft loss and plain-text Markdown display. Final scoped/static/domain/browser checks are recorded in test-evidence.json.

No unmitigated critical issue was found in this scope. This is not a production security certification. Open gates: exact remote0006 SQL approval/ACL proof, provider account policy, production accounting reconciliation/process-kill/distributed qualification, independent human calibration, native mic/mobile/assistive-device matrix and the existing midnight date-picker refresh limitation. Keep one application worker and public release HOLD.
