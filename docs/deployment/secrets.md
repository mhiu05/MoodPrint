# Secrets và cấu hình chạy

Frontend không cần biến `VITE_*`; mọi request tới `/api/v1` trên cùng origin. Chỉ nội dung JS/asset được public. `SUPABASE_PUBLISHABLE_KEY` không phải credential đặc quyền nhưng backend dùng để gọi Supabase Auth; không có lý do bake nó vào frontend. Tuyệt đối không đưa `DATABASE_URL`, `OPENAI_API_KEY`, `VOYAGE_API_KEY`, service-role key hoặc token vào image/JS/CI log.

Backend đọc tên biến thật trong `backend/app/core/config.py` và `backend/app/ai/embedding_config.py`. Mẫu là `deploy/runtime.env.example`. Bắt buộc cho `APP_ENV=production`: `DATABASE_URL` (runtime DML role, TLS), `SUPABASE_URL` HTTPS, `SUPABASE_PUBLISHABLE_KEY`, `FRONTEND_ORIGIN` HTTPS. Ứng dụng fail startup nếu thiếu. `COOKIE_SECURE=true` trong mẫu; production code cũng ép Secure cookie. `DATABASE_MIGRATION_URL` chỉ cấp cho một thao tác migration được duyệt, không lưu trong env runtime. `APP_DOMAIN` nằm ở `deployment.conf`, khớp host của `FRONTEND_ORIGIN`.

`AI_ENABLED=true` cần `OPENAI_API_KEY` và `OPENAI_MODEL`; `STT_ENABLED=true` cần cùng key và `STT_MODEL`; `SEMANTIC_MEMORY_ENABLED=true` cần `VOYAGE_API_KEY`. Các cờ này mặc định false ở mẫu. `AI_ACCOUNTING_ENABLED` chỉ bật khi schema và chính sách giá đã review. `CHAT_HISTORY_ENABLED` cũng cần schema 0007+. `DATABASE_POOL_MODE=session` cho runtime; migration dùng direct hoặc session connection riêng. Pool, concurrency, timeout, retention và Voyage model/dimensions có default trong source; đổi theo kết quả đo tải, không tự mở rộng worker. `AI_LOCAL_TEST_USER_IDS=[]` và `SANDBOX_ENABLED=false` ở production.

Một SecureString chứa env file backend. Parameter Store standard giới hạn 4 KB; nếu vượt, cân nhắc Secrets Manager hoặc tách parameter có IAM policy cập nhật. Dùng customer managed KMS key cho ranh giới decrypt hẹp; kiểm tra phí KMS. Script EC2 tải bí mật tới `/run/moodprint/runtime.env` mode 600 và không in nội dung. `docker inspect` vẫn cho root trên host xem environment; chỉ người vận hành tin cậy có quyền Docker/SSM. Không để backup hay CloudWatch thu file này. [Parameter Store SecureString](https://docs.aws.amazon.com/systems-manager/latest/userguide/secure-string-parameter-kms-encryption.html).

Khi quay vòng key: cập nhật SecureString qua kênh bí mật, gọi lại deploy workflow với **SHA mới đã được duyệt** hoặc một thủ tục SSM operator riêng đã review; xác minh health. Không dùng lệnh `docker compose config` với secret env file trong log CI. Backend log request ID/loại lỗi; Caddy không bật access log và runtime logger lọc URI/headers. Kiểm tra log redaction với token synthetic trong staging.
