# Review migration trước staging

Alembic source hiện là **`0010_account_deletion`**: `0001_foundation → 0002_safety → 0003_lifecycle → 0004_eligibility → 0005_export_scope → 0006_ai_usage → 0007_chat_history → 0008_memory_proposals → 0009_memory_embeddings → 0010_account_deletion`. `deploy/README.md` từng ghi 0005 là tài liệu cũ; báo cáo 0009 cũng chưa đủ cho API hiện tại. `/api/v1/health/ready` đòi **0010** và `moodprint.is_provider_session_active(uuid,uuid)`. Probe **read-only** ngày 25/10/2026 qua cả `DATABASE_URL` và `DATABASE_MIGRATION_URL` đã kết nối đúng Supabase Auth project, TLS mode `require`, thấy revision **0010**, private Auth bridge tồn tại và runtime role có quyền EXECUTE. Runtime role không có direct `auth.sessions` SELECT; đó là ranh giới chủ ý qua helper. Điều này xác nhận metadata hiện tại, chưa thay thế SQL/backup/restore review.

| Revision | Cần review trước khi chạy trên Supabase |
| --- | --- |
| 0006 | `ai_usage`, RLS/ACL runtime, tài khoản usage; chỉ bật `AI_ACCOUNTING_ENABLED` sau xác nhận. |
| 0007 | `ai_preferences`, conversations/messages/turns; nội dung chat và thời hạn giữ; mặc định opt-in từng người. |
| 0008 | `memory_proposals` và các khóa/ACL; proposal không được tự động coi là approved memory. |
| 0009 | `extensions.vector`, pgvector đúng schema, jobs/embeddings với RLS, vector dimensions và grants. Cần quyền `CREATE EXTENSION`/schema phù hợp; không tự chuyển extension đang có. |
| 0010 | Function `moodprint.delete_provider_identity` là `SECURITY DEFINER`, xóa `auth.users` **chỉ sau khi app user đã `deleted`**. Cần owner có quyền Auth phù hợp, kiểm tra search_path, `REVOKE PUBLIC`/grant riêng, trigger/cascade và thử trên DB disposable. |

Trước DDL remote: sao lưu Supabase và kiểm tra restore vào **project mới** bằng dữ liệu synthetic/được phép; xác minh project ID, host, schema, role, `alembic_version`, extensions và SQL tạo bởi từng revision. Migration owner tách runtime role. Kiểm tra các grant DML mới và quyền `auth.sessions(id,user_id)` tối thiểu cho helper; xác minh RLS/private `moodprint` không mở cho Data API. Thử migration trong PostgreSQL disposable có pgvector rồi review diff; lấy chấp thuận riêng mới được chạy remote. Trong task này chỉ gọi hàm kiểm tra read-only của `scripts/inspect_database.py`, chỉ in status/revision/boolean metadata, không chạy DDL. [Supabase backups](https://supabase.com/docs/guides/platform/backups), [restore to new project](https://supabase.com/docs/guides/platform/clone-project).

Các downgrade 0006–0010 cố ý từ chối rollback phá dữ liệu. Rollback ứng dụng dùng image cũ **chỉ nếu tương thích schema mở rộng**. Restore DB là thao tác độc lập có downtime và có thể hồi sinh tài khoản/memory đã xóa; trước khi mở traffic phải đối soát tombstone, consent, revocation và deletion queue. Không backup RAM transcript. Mất state RAM khi restart/release: stream đang chạy gián đoạn, cần người dùng thử lại; không tự replay model call. Staging không được mở AI/memory/account deletion khi schema hoặc quyền chưa xác nhận.
