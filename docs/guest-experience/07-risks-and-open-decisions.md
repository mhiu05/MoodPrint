## 4. Unverified external boundaries

Anonymous sign-ins being enabled is accepted as user-provided context; no Dashboard settings were changed. Hosted catalog access verified revision/RLS/helper grants, not live anonymous signup, CAPTCHA settings, all CRUD grants, Data API exposed-schema configuration or Auth delete cascade with a synthetic user. The verified source uses PostgreSQL backend ownership; do not invent a completed per-end-user RLS system.

OpenAI retention controls and Voyage project terms must be checked for the selected models/endpoints. `store=False`/tracing disabled are client behaviors (`ai/provider.py:199–212`), not proof of universal two-hour provider erasure. Guest semantic memory can remain off while ordinary approved memory/lexical retrieval stays available. Database backup/PITR settings, retention/redaction of deployed logs and isolated restore behavior were not certified.

Supabase changelog was checked on audit date. The upcoming CBC TLS1.2 cipher removal is scheduled no earlier than2026-11-10; normal supported clients should be verified during staging, not worked around by weakening TLS. [Official deprecation notice](https://supabase.com/changelog/cbc-tls-ciphers-deprecated). This is a compatibility watch item, not evidence of a current MoodPrint failure.

No AWS infrastructure change is needed for the proposed topology. If future work creates or changes AWS resources, follow repository AWS Region/paid-plan/spend/approval rules then. This audit did not query or infer those settings from the Supabase Region.
