# S-02 — SQLAlchemySession persistence và schema

Trạng thái: **VERIFIED** trên PostgreSQL local, Agents SDK `0.24.0`, SQLAlchemy `2.1.8`.

- `SQLAlchemySession` nhận engine có `schema_translate_map={None: "agent_store"}`, `create_tables=False`, `ensure_ascii=False` và `SessionSettings(limit=100)`.
- `backend/tests/integration/test_sdk_schema.py` so sánh metadata của SDK với bảng do SQL migration tạo.
- `agent/tests/integration/test_session_postgres.py` ghi câu tiếng Việt, dispose engine, tạo engine/session mới và đọc lại đúng item. SQL đọc `message_data` xác nhận chữ có dấu còn nguyên UTF-8, không thành escape `\\u...`.
- `backend/tests/integration/test_conversations.py` xác nhận owner khác bị từ chối trước khi mở session, transcript độc lập với SDK replay và xóa conversation dọn SDK rows.
- SQLAlchemy có thể bổ sung khóa nội bộ `_none` vào execution options; assertion kiểm mapping của `None`, không giả định dict không có khóa nội bộ.

Không cần fallback `search_path`; không gọi `create_all`. Kết quả suite cuối và command được ghi tại báo cáo Phase 0. Spike không xác nhận persistence hosted.
