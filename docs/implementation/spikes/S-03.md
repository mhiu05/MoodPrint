# S-03 — RunState restart/resume và approval

Trạng thái: **VERIFIED** offline với Agents SDK `0.24.0` và `ScriptedModel`; **VERIFIED** persistence của approval qua PostgreSQL local.

## Thực nghiệm

- `agent/tests/test_runtime.py`: tool write test-only dừng trước khi thực thi; tạo runtime và registry mới, deserialize checkpoint với context mới rồi approve/reject. Chỉ approve chạy tool.
- `agent/tests/test_approval_process.py` dùng hai Python subprocess riêng: process đầu serialize SDK RunState; process sau tạo Agent/registry mới và resume. Không cần API key hoặc live model.
- `backend/tests/integration/test_agent_approval.py`: lưu checkpoint vào `app.tool_approvals`, owner B không quyết định được; quyết định lần hai trả conflict; runtime mới resume thành công và transcript được persist.
- Checkpoint dùng `context_serializer=lambda _: {}`. Regression tests xác nhận không có `claims_json` hoặc auth canary. Context luôn được dựng lại sau xác thực; client không nhận serialized state hay raw arguments.
- Regression RED phát hiện SDK trả usage tích lũy sau resume: 7 tokens trước pause + 12 tokens sau pause bị cộng thành 26. Persistence đã đổi sang lưu counters tích lũy: kết quả đúng **19 tokens, 2 requests, 1 tool call**.

## Sai khác API đã xác minh

Pinned SDK dùng `function_tool(timeout=...)`; `RunState.from_string` là async và nhận `context_override=RunContextWrapper(ctx)`. `OpenAIResponsesCompactionSession` được import từ `agents.memory`.

Không dùng fallback `prepare` vì restart/resume đã chạy được. Tool write chỉ tồn tại trong test; Phase 0 production registry chỉ có `get_server_time`. Spike không xác nhận hosted hoặc live model.
